# n8n + PostgreSQL 云服务器部署指南 (新手版)

你好！欢迎使用这个 n8n 部署工具。你可以把它想象成一个“乐高积木豪华套装”，能帮你快速在自己的云服务器上搭建起强大的自动化工具 n8n。

这套“乐高”包含两个核心部件：
1.  **n8n**: 大脑，负责设计和运行各种自动化流程。
2.  **PostgreSQL**: 仓库，一个可靠的数据库，专门存放 n8n 的所有数据。

---

## 🚀 三步完成部署，就像拼乐高一样简单

### 第一步：配置“图纸” (`.env` 文件)

`.env` 文件就是我们这套乐高的“搭建图纸”，里面记录了一些关键信息。你需要根据自己的情况修改它。

1.  **打开 `.env` 文件。**
2.  **修改密码：** 找到 `POSTGRES_PASSWORD` 和 `POSTGRES_NON_ROOT_PASSWORD`，把等号后面的默认密码改成你自己的，一定要复杂一些！这相当于给你的“仓库”上两把锁。
3.  **检查端口：** `N8N_PORT` 默认是 `5678`。这就像你家的门牌号。如果这个数字没被其他程序占用，就不用改。

### 第二步：在服务器上准备“地基” (关键步骤！)

我们的“乐高”需要一块专门的地方来存放文件，比如 n8n 工作流中生成的图片、文档等。

**在启动之前，你必须先在你的云服务器上创建这个文件夹。**

打开你服务器的命令行工具，输入以下命令：

```bash
# 在 /home/ubuntu/ 目录下创建一个名为 n8n_files 的文件夹
mkdir -p /home/ubuntu/n8n_files
```

**重要提示：**
*   `docker-compose.yml` 文件中默认的路径是 `/home/ubuntu/n8n_files`。如果你的服务器用户名不是 `ubuntu`，请把命令中的 `ubuntu` 换成你的用户名，比如 `/home/myuser/n8n_files`。
*   同时，你还需要**同步修改 `docker-compose.yml` 文件第 60 行**的路径，确保两边完全一致。

### 第三步：启动！

万事俱备！现在，回到你存放 `docker-compose.yml` 文件的这个目录，运行下面的命令，我们的“乐高”就会开始自动搭建了。

```bash
docker-compose up -d
```

看到 `done` 或者没有报错信息，就代表启动成功了！

## 🎉 如何访问你的 n8n

在浏览器地址栏输入：`http://你的服务器IP地址:5678` (如果你修改了端口，请使用你自己的端口号)。

第一次登录 n8n，它会引导你设置一个管理员账号和密码，请一定记好。

## ⚙️ 日常维护

### 更新版本

想给 n8n 升级到最新版？很简单，只需两步：

```bash
# 1. 拉取最新的“乐高零件”
docker-compose pull

# 2. 重新搭建
docker-compose up -d
```

### 停止服务

临时关闭 n8n：

```bash
docker-compose stop
```

### 彻底拆除

如果你不想要了，可以彻底删除它（注意：数据库和 n8n 的数据也会被删除！）：

```bash
docker-compose down
```

## ☁️ 关于 Cloudflare 隧道 (高级功能)

如果你想通过自己的域名（比如 `n8n.yourdomain.com`）来访问 n8n，可以启用 `docker-compose.yml` 文件中被注释掉的 `cloudflare-tunnel` 服务。这是一个高级功能，需要你先了解 Cloudflare Tunnel 的用法。对于新手，建议先跳过。
